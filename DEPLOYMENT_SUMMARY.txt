1. PERSIAPAN LOKAL:
   □ Copy .env.example → .env
   □ Generate SECRET_KEY baru
   □ Edit .env dengan nilai production
   □ Run: pre_deploy_check.bat
   □ Test: python manage.py runserver

2. UPLOAD KE HOSTING:
   □ Upload semua file ke /public_html/webtest/
   □ Upload .env terpisah (security)
   □ Set permission file

3. SETUP DATABASE (cPanel):
   □ Buat database: usernamecpanel_web_smknj_db
   □ Buat user: usernamecpanel_dbuser
   □ Add user ke database dengan ALL PRIVILEGES

4. SETUP PYTHON APP (cPanel):
   □ Setup Python App
   □ Install dependencies
   □ Restart app

5. MIGRASI & SETUP:
   □ python manage.py migrate
   □ python manage.py collectstatic
   □ python manage.py createsuperuser

6. TESTING:
   □ Test homepage
